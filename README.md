# ClientePedidos1App

This is a simple Android application built to manage clients and their corresponding orders. The app provides a clean and modern user interface for viewing, adding, editing, and deleting client and order information.

## Features

*   **Home Screen:** A central navigation point to access different features of the app.
*   **Client Management:**
    *   View a list of all clients.
    *   Add new clients to the database.
    *   Edit existing client details.
    *   Navigate to see the orders for a specific client.
*   **Order Management:**
    *   View a list of orders for each client.
    *   Add new orders for a client.
    *   Edit existing orders.
*   **Modern UI:** A clean and modern user interface built with the latest Material Design components.
*   **Robust Architecture:** The app uses a modern architecture with an `AppContainer` for dependency management and a centralized `ViewModelFactory`.

## Technologies Used

*   **Kotlin:** The primary programming language for the app.
*   **Jetpack Compose:** Used for building the user interface.
*   **Material Design 3:** Provides the design system and components for the UI.
*   **Room Persistence Library:** Used for local data storage.
*   **Jetpack Navigation:** Used for navigating between screens.
*   **Kotlin Symbol Processing (KSP):** Used for annotation processing.
*   **Gradle:** Used for building the project.

## Setup

1.  Clone the repository to your local machine.
2.  Open the project in Android Studio.
3.  Build and run the project on an Android device or emulator.
